## 01 // Vision & Creative Direction

Convertix is designed as a **$10,000–$20,000 agency-grade luxury editorial brand experience** inspired by high-fashion automotive campaigns, ADVIK EWC art direction, and modern enterprise software architecture.

- **Monochromatic Obsidian Foundation**: Near-black (`#0A0A0A`), warm ivory white (`#F3F1EC`), editorial gray (`#B8B5AF`), and a single restrained automotive luxury accent (`#E05A2B` Burnt Automotive Orange).
- **Oversized Typography Hierarchy**: 80–160px headlines utilizing `Space Grotesk` display paired with refined `Playfair Display` and `Cormorant Garamond` serif accents.
- **Asymmetric Editorial Layouts**: Full-bleed magazine compositions, high negative space, and hairline dividers replacing generic SaaS card grids.
- **Sub-Second Performance**: `content-visibility` rendering deferrals, hardware-accelerated transforms, and zero-dependency Web Audio API sound feedback.

## 02 // Core Architectural Suites

### 1. Lead & Pre-Sales Velocity OS (`/products/lead-management`)
- **First Contact Latency**: Slashes response delay from **6–24 hours** down to **10–30 minutes**.
- **SIM-Integrated Calling**: Native mobile SIM outbound dialing with zero hardware PBX lag, automatic call logging, and duration audits.
- **2-Way OEM DMS Sync**: Bi-directional integration with Tata Motors, Maruti Suzuki, Hyundai Motor, and Mahindra & Mahindra dealer systems.
- **Hierarchical Inactivity Sentinels**: Automatic supervisor escalations on leads unattended for &gt;15 minutes or 24 hours.

### 2. Service & Insurance Retention OS (`/products/service-insurance`)
- **Predictive Mileage Extrapolation**: Calculates exact vehicle inspection dates using historical driving frequency algorithms, reducing mistimed reminders from **&gt;60%** to **&lt;10%**.
- **60-Day Insurance Expiry Radar**: Multi-channel 60/30/15-day renewal reminder sequences that lift policy retention past **&gt;90%**.
- **1-Click WhatsApp Workshop Booking**: Frictionless customer bay reservation and vehicle pickup scheduling without phone tag delays.

## 04 // Getting Started & Local Development

### Prerequisites
- Node.js 18+ or 20+
- npm, pnpm, or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/aariya11/CONVERTIX-rrefined-.git

# Navigate into the project directory
cd CONVERTIX-rrefined-

# Install dependencies
npm install

# Start development server with Turbopack
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build
```bash
# Compile optimized production build
npm run build

# Start production server
npm run start
```
